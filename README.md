# Ismail Victor Elias — Portfolio

A responsive, static portfolio starter for GitHub Pages.

## Files
- `index.html` — page structure, metadata, and Person structured data
- `styles.css` — responsive dark navy / cyan design
- `script.js` — accessible mobile navigation
- `robots.txt` and `sitemap.xml` — basic search-crawler hints
- `assets/favicon.svg` — site icon

## Before publishing: important personalisation
1. Confirm the exact LinkedIn URL and GitHub profile links.
2. Replace the generic GitHub links in the CS-03 card with the exact repository URL.
3. Replace `hello@example.com` in the engineering card or remove that link.
4. Add a verified certificate link and real screenshots/evidence for completed projects.
5. Confirm the education wording and dates; don't publish unconfirmed qualifications.
6. Update the canonical URL and sitemap if you use a different domain.
7. Add a professional photo only if you want one; optimise it and write accurate alt text.

## Preview locally
Open `index.html` in a browser. No build tools or external libraries are required.

## Publish on GitHub Pages
1. Create a new repository, e.g. `ismail-victor-elias-portfolio`.
2. Upload all files while preserving the `assets/` folder.
3. In repository Settings → Pages, choose deploy from the `main` branch and root folder.
4. Wait for GitHub Pages to publish, then open the provided URL.
5. To keep the existing portfolio unchanged, publish to the new repository first. You can switch the old repository over only after checking the new version.
6. Add the final live URL to Google Search Console and request indexing. Indexing is not guaranteed or immediate.

## Accuracy and privacy
This site intentionally avoids fabricated performance metrics, employers, and certifications. Only add claims you can support with evidence. Do not publish private IPs, credentials, sensitive logs, personal phone numbers, or other confidential lab data.
